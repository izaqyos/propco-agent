# Live evaluation

The unit, component and end-to-end suites run against a scripted fake model, so they are deterministic and prove the code paths. This file records what happens with a **real** model: the demo question set through the whole graph, asserting intent, key figures and clarification behaviour. Run it with `make eval` (`pytest -m live`); it skips when the configured provider is unreachable and writes a JSON report to `tests/eval/reports/`.

Observations.

1. Routing: 12/12 intents correct or immaterial (compound and clarification cases are not intent-checked, same as the Ollama run), including Dutch and the injection attempt.
2. 5. `gemini-3.5-flash-lite` ignores the `temperature` parameter (fixed sampling defaults) — a harmless SDK warning, not an error; router/extractor determinism is already handled by structured-output validation, not by temperature.
